# User Vision & Conversation Knowledge Base

## Core Directives & Vision
- **Theme**: "I contain multitudes." The user is a multidisciplinary engineer (Cloud/DevOps, SDET, Innovation Tech, Reliability, QA/Automation, Quantum Research). The site must not flatten this identity into a single title.
- **Visual Aesthetic**: Highly immersive, dynamic, Apple-tier cinematic experience. "Beautifully crafted experience", "fading effect like iphone duo", "dynamic elements easter eggs ux components glass effects".
- **Reference Portfolios**:
  - https://www.aashishthakuri.com/about (Primary inspiration for heavy typography, scroll-jacking, dynamic UI)
  - https://www.sunnypatel.net/
  - https://www.gmmohit.com/
  - https://ajokano.com/en/
  - https://ilhamriski.com/
  - https://annachope.com/index.html
  - https://mahesh.lol/
  - https://movierecommendation-two.vercel.app/
  - https://rohitmehta.vercel.app/
  - https://davej.com/
- **Structure**: "Whole journey should go in one flow if user wants but it should have multipage structure." Detailed deep dives available upon clicking (e.g., /about, /experience, /toolkit).
- **Modes / Themes**: A plethora of 10-15 modes accessible via a top toggle. "Light, dark, gray, old school, classical, minimal, modern, paper, aurora, terminal, etc." Each mode must have matching fonts, color schemes, and dynamic atmospheric backgrounds ("switching worlds").
- **Tools / Ecosystem**: Needs "colorful illustrated icons" for tools. Must explicitly include AI, Agents, VS Code, GitHub, Gemini, Claude, Prompt Engineering, Antigravity.
- **Certifications**: Must include embedded links to specific certificates (Coursera ML, AZ-900, Salesforce, IEEE Paper). Data must be kept locally in the project.
- **Personal Links**: Spotify, Apple Music, LinkedIn, GitHub must be integrated.
