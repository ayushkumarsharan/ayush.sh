- **"Explore Ayush" AI Assistant**: Instant client-side zero-hallucination knowledge engine.
- **Living Lab Archive**: A dedicated sandbox for ongoing prototypes, AI test generators, and shaders.
- **Single Source of Truth**: All data isolated in clean, type-safe TypeScript files in `/content`.

## 🛠️ Local Development

Ensure you have Node.js (v18+) installed:

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open browser at:
http://localhost:3000
```

## 🚀 Free Hosting & Deployment

### Option 1: Vercel (Recommended — Zero Configuration)
1. Push this repository to your GitHub account (`https://github.com/your-username/my-website`).
2. Log into [vercel.com](https://vercel.com) with GitHub.
3. Click **"Add New Project"** → Import your repository → Click **"Deploy"**.
4. Your website is live worldwide on a fast global Edge network with free SSL.

### Option 2: GitHub Pages (Automated via GitHub Actions)
1. Push code to the `main` branch.
2. In your GitHub repository settings, navigate to **Settings** → **Pages** → Source: **GitHub Actions**.
3. The `.github/workflows/deploy.yml` pipeline will automatically build and deploy the site.
